# Granada source data

This directory is reserved for the four authorized source tables: `Patient_info.csv`, `Glucose_measurements.csv`, `Biochemical_parameters.csv`, and `Diagnostics.csv`. They are not included in the public repository.

Obtain access through the [dataset publication](https://www.nature.com/articles/s41597-023-02737-4) and follow its data-use agreement. Keep the original files unchanged. See [data access and artifact layout](../../DATA_ACCESS.md) before running preparation.
